# Backend

Backend duoc tach rieng theo yeu cau do an.

## Cong nghe

- Node.js
- Express
- MongoDB + Mongoose
- RESTful API

## Cau truc

- `bin/`: khoi dong server
- `routes/`: dinh tuyen API
- `services/`: xu ly nghiep vu
- `repositories/`: truy cap du lieu
- `schemas/`: Mongoose schema
- `middlewares/`: middleware xac thuc, phan quyen
- `utils/`: ham dung chung
- `uploads/`: file upload

## Chay du an

```bash
cd backend
npm install
npm run dev
```

Mac dinh server chay `http://localhost:3000`.
